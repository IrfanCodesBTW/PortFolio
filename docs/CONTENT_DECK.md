# Content Deck

All strings live in `src/data/content.ts` and `src/data/projects.ts`. This file is the source for tone, not a second copy to duplicate — if you change a line, change it in the data file.

## Voice

- First person, present tense, short sentences.
- Specific over clever. One dry line is allowed per section, never two.
- Numbers as proof, never as decoration.
- Admit boundaries. "Concept", "study", "prototype" are strengths here.
- Banned: passionate, cutting-edge, solutions, journey, crafting digital experiences, elevate, unlock, seamless, robust.
